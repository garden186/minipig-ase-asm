# ASM analysis

## Extraction and individual inference

The public extraction harness uses the original single-CpG read/fragment engine. It preserves MAPQ0, conversion-aware allele evidence, reference CpG coordinates, genotype-disruption masking, QNAME mate grouping, exact phase sets and independent evidence replay.

Create a tab-separated manifest using `config/asm_counts.example.tsv`. Paths resolve beside the manifest. The FASTA is the unmasked assembly reference for CpG enumeration; the BAM was aligned against the animal's N-masked reference. Phased and original genotype VCFs must contain the matching animal. Indexed, coordinate-sorted BAMs and indexed VCFs are required.

```sh
python scripts/run_analysis.py asm-count --manifest asm_counts.tsv --output new_raw_counts \
  --chromosomes 1 --stop-after-tiles 1
```

This is an explicit small execution check. It is not genome-wide output. For a full run, use a new output directory, omit both scope-limiting options, and include the complete 30-unit manifest. The new harness is sequential and conservative; original cluster migration/deployment wrappers are not redistributed. It records source/code identities and validates each tile. It does not overwrite incomplete tile directories.

```sh
python scripts/run_analysis.py asm-gq20 --tiles FULL_COUNTS/completed_tiles.json --output new_gq20
python scripts/run_analysis.py asm-individual --manifest new_gq20/counts_manifest.json \
  --fai reference.fa.fai --output new_individual_ASM --bh-memory-gib 16
```

GQ20 reassignment uses phased GQ, or exact-allele/genotype-matched original genotype GQ only when phased GQ is missing. Eligible tests require H1≥3, H2≥3 and combined depth≥10. Two-sided Fisher uses probability ordering. The new individual interface includes complete within-unit, tissue10 and global30 BH families; it rejects a missing animal/tissue or incomplete chromosome tiling. There is no significance, effect-size or promoter prefilter for BH. Approximately 59 million tested observations require substantial memory and disk; the interface checks a BH working-memory estimate.

## Common anchors, directional recurrence and paired tissues

The full original scientific controllers are in:

- `asm_allele_prep`: original raw CpG/PS availability, tested-count caches and WGS phase records; P-independent common-anchor preparation.
- `asm_directional`: aligned ALT/REF count tables, exact one-sided tails, Fisher partial conjunction, 54 complete tissue×r×direction families and two-direction adjustment.
- `asm_tissue_comparison`: the adopted aligned paired-tissue pipeline, exact equal-OR test on full conditional support and 27 complete pair×r families. It does not gate hypotheses by observed sign.

These controllers expose input locations through `MINIPIG_ANALYSIS_CONFIG` and external regression/reference assets through `MINIPIG_ASSETS`. Their `assets_manifest.json` files specify required hashes. The per-stage JSON must contain the native source schemas and input identities, not merely a BAM path. [Native configuration schemas](ASM_CONFIG.md) describes these inputs.

```sh
export MINIPIG_ANALYSIS_CONFIG=/my/private/directional_inputs.json
export MINIPIG_ASSETS=/my/external/directional_assets
python analysis/asm_directional/selftest.py --record directional-tests.json
python scripts/run_analysis.py asm-recurrence run --output NEW_OUTPUT \
  --workers 2 --test-record directional-tests.json
```

**Remaining interface boundary:** the new raw-count/individual outputs are not automatically converted into the original controller cache/receipt formats. Native caches, full source registries and original frozen regression assets must currently be supplied separately. The package contains the original analysis code; a fresh whole-genome reconstruction through these interfaces has not yet established end-to-end equivalence. Do not edit validation hashes or receipts to bypass this boundary.

For the original final data, directional r≥2 results are Heart 977, Kidney 1,084 and Liver 1,451 tissue–CpG rows, with 2,197 unique CpGs. These are historical checks, not results generated by this public checkout.

## Annotation, GO and integration

Build the annotation index with `scripts/run_analysis.py annotation --gtf ... --output ...`. The original protein-coding/canonical-transcript promoter and feature rules are retained. The default GTF SHA256 is taken from the original annotation release. If the supplied file is a differently packaged but intended reference, investigate and explicitly record its identity instead of silently disabling checks.

For GO, `Rscript analysis/go/enrich_final.R config.json` accepts `gene_universe`, `go_annotation`, `output`. Run each tissue/mode separately. The universe table contains unique `gene_id` and `selected` (0/1); the annotation contains `go_id`, `gene_id`, `go_name` from the frozen corrected Ensembl115 BP annotation. Use the complete eligible gene opportunity background (N≥2 in the final recurrence analysis), not significant genes as background. Native `enricher` uses BP term sizes 10–500 and BH over its tested positive-overlap terms. The script independently checks membership, hypergeometric probabilities and BH. R/GO execution has not been repeated in the Windows curation session.

See [integration input contract](INTEGRATION.md) for the original same-PS/same-transcript join and signed effects.

`annotate-cpgs` appends index-derived annotations to a CpG TSV. `asm-composition` forms one physical-CpG union per animal across the three tissues, separately for P<0.05 and global30 BH≤0.05. Canonical exon overlap is a separate, non-exclusive feature. No-direct and other-gene CpGs stay in the denominator.

`external-overlap` accepts a CpG table and a peak manifest with `track`, `replicate`, `path`, `sha256`, `minimum_replicates`. Supply BED/narrowPeak intervals as 0-based half-open coordinates. The final replicated external tracks require ≥2 source replicates; a precomputed consensus interval set uses 1. Convert published classification tables to this explicit BED schema before input; the script does not infer source-specific coordinate conventions. It emits exact CpG point membership and replicate counts without plotting or enrichment tests.
